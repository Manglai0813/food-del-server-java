# 開発環境設定ガイド

## 概要

Java 21 + Spring Boot 3 プロジェクトの開発環境をセットアップする手順を説明するドキュメントです。

## 前提条件

### 必要なソフトウェア

- **Java 21**: JDK 21 以上
- **Maven 3.8+** または **Gradle 8+**: ビルドツール
- **PostgreSQL 14+**: データベース
- **IDE**: IntelliJ IDEA（推奨）または Eclipse、VS Code
- **Git**: バージョン管理

---

## セットアップ手順

### 1. Java 21 のインストール

#### 1.1 JDK のダウンロード

**選択肢**:
- **Oracle JDK 21**: Oracle 公式
- **OpenJDK 21**: オープンソース
- **Amazon Corretto 21**: Amazon 提供
- **Eclipse Temurin 21**: Eclipse 提供

**推奨**: Eclipse Temurin 21（無料、長期サポート）

#### 1.2 インストール確認

```bash
java -version
# 出力例: openjdk version "21.0.1" 2024-10-15
```

---

### 2. PostgreSQL のセットアップ

#### 2.1 PostgreSQL のインストール

**Linux (Ubuntu/Debian)**:
```bash
sudo apt update
sudo apt install postgresql-14
```

**macOS**:
```bash
brew install postgresql@14
```

#### 2.2 データベースの作成

```bash
# PostgreSQL に接続
sudo -u postgres psql

# データベース作成
CREATE DATABASE food_delivery;

# ユーザー作成（オプション）
CREATE USER food_user WITH PASSWORD 'your_password';
GRANT ALL PRIVILEGES ON DATABASE food_delivery TO food_user;
```

---

### 3. 環境変数の設定

#### 3.1 `.env` ファイルの作成

プロジェクトルートに `.env` ファイルを作成：

```env
# データベース設定
DATABASE_URL=jdbc:postgresql://localhost:5432/food_delivery
DB_USERNAME=postgres
DB_PASSWORD=your_password

# JWT 設定
JWT_SECRET=your-super-secret-key-at-least-32-characters-long
JWT_REFRESH_SECRET=your-refresh-secret-key-at-least-32-characters-long

# サーバー設定
SERVER_PORT=5000
SPRING_PROFILES_ACTIVE=dev

# CORS 設定
CORS_ALLOWED_ORIGINS=http://localhost:3000,http://localhost:3001
CORS_ALLOW_CREDENTIALS=true
```

#### 3.2 `application.yml` の設定

`src/main/resources/application.yml`:

```yaml
spring:
  datasource:
    url: ${DATABASE_URL}
    username: ${DB_USERNAME}
    password: ${DB_PASSWORD}
    driver-class-name: org.postgresql.Driver
    hikari:
      maximum-pool-size: 10
      minimum-idle: 5
  
  jpa:
    hibernate:
      ddl-auto: update
    show-sql: true
    properties:
      hibernate:
        format_sql: true
        dialect: org.hibernate.dialect.PostgreSQLDialect

server:
  port: ${SERVER_PORT:5000}

jwt:
  secret: ${JWT_SECRET}
  refresh-secret: ${JWT_REFRESH_SECRET}
  access-token-validity: 604800000  # 7日
  refresh-token-validity: 2592000000  # 30日
```

---

### 4. アプリケーションの起動

#### 4.1 IDE から起動

**IntelliJ IDEA**:
1. `FoodDeliveryApplication.java` を開く
2. 右クリック → "Run 'FoodDeliveryApplication'"

#### 4.2 コマンドラインから起動

**Maven**:
```bash
mvn spring-boot:run
```

**Gradle**:
```bash
./gradlew bootRun
```

---

### 5. 動作確認

#### 5.1 ヘルスチェック

```bash
curl http://localhost:5000/
# 期待されるレスポンス: {"message":"Welcome to Food Delivery API"}
```

## トラブルシューティング

### 1. Java バージョンエラー

**問題**: "Unsupported class file major version"

**解決方法**:
- Java 21 が正しくインストールされているか確認
- `JAVA_HOME` が正しく設定されているか確認

### 2. データベース接続エラー

**問題**: "Connection refused" または "Authentication failed"

**解決方法**:
- PostgreSQL が起動しているか確認: `sudo systemctl status postgresql`
- データベース名、ユーザー名、パスワードが正しいか確認

### 3. ポート競合

**問題**: "Port 5000 is already in use"

**解決方法**:
- 別のポートを使用: `server.port=5001`
- または既存のプロセスを停止
