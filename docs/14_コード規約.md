# コード規約

## 概要

Java 21 + Spring Boot 3 プロジェクトのコーディング規約とベストプラクティスを定義するドキュメントです。

## 命名規則

### パッケージ名

**規則**: 小文字のみ、単語は区切らない

**例**:
- `com.fooddel.controller`
- `com.fooddel.service.impl`
- `com.fooddel.repository`

### クラス名

**規則**: PascalCase（大文字始まり、各単語の頭文字を大文字）

**例**:
- `UserController`
- `OrderService`
- `FoodRepository`
- `ApiResponse`

### メソッド名

**規則**: camelCase（小文字始まり）

**例**:
- `getUserById()`
- `createOrder()`
- `updateStock()`

### 変数名・フィールド名

**規則**: camelCase

**例**:
- `userId`
- `totalAmount`
- `isAuthenticated`

### 定数名

**規則**: UPPER_SNAKE_CASE（大文字、アンダースコア区切り）

**例**:
- `MAX_RETRY_COUNT`
- `DEFAULT_PAGE_SIZE`
- `JWT_TOKEN_EXPIRATION`

---

## コーディングスタイル

### インデント

**規則**: スペース4つ（タブは使用しない）

### 行の長さ

**規則**: 最大120文字

### 中括弧

**規則**: K&R スタイル（開き括弧は行末）

```java
if (condition) {
    // コード
} else {
    // コード
}
```

---

## エラーハンドリング

### 例外の使用

**規則**:
- ビジネス例外: カスタム例外クラスを使用
- システム例外: 標準例外を使用

**例**:
```java
if (stock < quantity) {
    throw new StockException("在庫が不足しています");
}
```

---

## ログ記録

### ログレベル

**規則**:
- `ERROR`: エラー（処理が続行できない）
- `WARN`: 警告（処理は続行できるが注意が必要）
- `INFO`: 情報（重要な処理の記録）
- `DEBUG`: デバッグ（開発時の詳細情報）

### ログメッセージ

**規則**: 機密情報（パスワード、トークン）は含めない

**例**:
```java
log.info("ユーザー {} がログインしました", userId);
log.error("注文作成に失敗しました: orderId={}", orderId, exception);
```

---

## 依存性注入

### コンストラクタインジェクション（推奨）

**規則**: `@Autowired` アノテーションは省略可能（Spring 4.3+）

**例**:
```java
@Service
public class UserServiceImpl implements UserService {
    private final UserRepository userRepository;
    
    public UserServiceImpl(UserRepository userRepository) {
        this.userRepository = userRepository;
    }
}
```

---

## トランザクション

### トランザクションアノテーション

**規則**: Service 層のメソッドに `@Transactional` を付与

**例**:
```java
@Transactional
public Order createOrder(CreateOrderRequest request) {
    // ...
}
```
