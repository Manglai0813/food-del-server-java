# トラブルシューティングガイド

## 概要

開発・運用中に発生する可能性のある問題とその解決方法をまとめたドキュメントです。

## よくある問題と解決方法

### 1. アプリケーション起動エラー

#### 1.1 ポート競合

**症状**: 
```
Port 5000 is already in use
```

**原因**: ポート 5000 が既に使用されている

**解決方法**:
1. 既存のプロセスを確認: `lsof -i :5000` または `netstat -an | grep 5000`
2. 既存のプロセスを停止
3. または別のポートを使用: `server.port=5001`

---

#### 1.2 データベース接続エラー

**症状**:
```
Connection refused
Authentication failed
```

**原因**: PostgreSQL が起動していない、または認証情報が間違っている

**解決方法**:
1. PostgreSQL の起動確認: `sudo systemctl status postgresql`
2. PostgreSQL を起動: `sudo systemctl start postgresql`
3. 接続情報の確認: `application.yml` のデータベース設定
4. データベースの存在確認: `psql -U postgres -l`
5. ユーザー権限の確認: `pg_hba.conf` の設定

---

#### 1.3 環境変数未設定

**症状**:
```
Missing required environment variables: JWT_SECRET
```

**原因**: 必須の環境変数が設定されていない

**解決方法**:
1. `.env` ファイルを作成
2. 必要な環境変数を設定
3. またはシステム環境変数に設定

---

### 2. データベース関連エラー

#### 2.1 マイグレーションエラー

**症状**:
```
Migration failed
Table already exists
```

**原因**: マイグレーションが既に実行されている、またはスキーマが不一致

**解決方法**:
1. マイグレーション履歴を確認
2. データベーススキーマを確認
3. 必要に応じてマイグレーションを手動で実行

---

#### 2.2 楽観的ロックエラー

**症状**:
```
OptimisticLockException
```

**原因**: 同時更新による競合

**解決方法**:
1. リトライロジックが実装されているか確認
2. 更新頻度を下げる
3. 悲観的ロックの使用を検討

---

### 3. 認証・認可エラー

#### 3.1 トークン無効エラー

**症状**:
```
Token is invalid
Token expired
```

**原因**: トークンが無効または期限切れ

**解決方法**:
1. トークンを再取得（ログインまたはリフレッシュ）
2. トークンの有効期限を確認
3. JWT Secret が正しいか確認

---

### 4. パフォーマンス問題

#### 4.1 レスポンスが遅い

**症状**: API のレスポンスタイムが長い

**原因**: 
- N+1 問題
- インデックス不足
- 大量データの取得

**解決方法**:
1. SQL ログを確認
2. `@EntityGraph` または `JOIN FETCH` を使用
3. インデックスを追加
4. ページネーションを実装

---

### 5. ファイルアップロードエラー

#### 5.1 ファイルサイズ超過

**症状**:
```
File size exceeds maximum
```

**原因**: ファイルサイズが制限を超えている

**解決方法**:
1. ファイルサイズ制限を確認: `spring.servlet.multipart.max-file-size`
2. ファイルサイズを小さくする
3. 制限を増やす（必要に応じて）

---

## ログの確認方法

### 1. アプリケーションログ

**場所**: 
- コンソール出力
- ログファイル（設定による）

**確認方法**:
```bash
tail -f logs/application.log
```

### 2. データベースログ

**SQL ログ**:
```yaml
spring:
  jpa:
    show-sql: true
    properties:
      hibernate:
        format_sql: true
```
