## 1. 概要

### 1.1 注文システムの役割

注文システムは、カート内の商品を実際の注文に変換し、在庫を確定的に減らす重要な機能です。

**主な責務**:

- ✅ カートから注文への変換
- ✅ 在庫の確定的な減算
- ✅ 注文ステータスの管理
- ✅ 注文履歴の記録

## 2. 注文ステータス

### 2.1 ステータス定義

[`OrderStatus.java`](file:///home/manglai/Projects/food-del-server-java/src/main/java/com/fooddel/constant/OrderStatus.java)

```java
public enum OrderStatus {
    PENDING,      // 保留中（支払い待ち）
    CONFIRMED,    // 確認済み（支払い完了）
    PREPARING,    // 準備中
    SHIPPED,      // 配送中
    DELIVERED,    // 配達完了
    CANCELLED     // キャンセル
}
```

### 2.2 ステータス遷移図

```
         ┌─────────┐
         │ PENDING │ ← 注文作成時
         └────┬────┘
              │
    ┌─────────┼─────────┐
    │         │         │
    ▼         ▼         ▼
CANCELLED  CONFIRMED  (タイムアウト)
            │
            ▼
        PREPARING
            │
            ▼
         SHIPPED
            │
            ▼
        DELIVERED
```

**遷移ルール**:

- `PENDING` → `CONFIRMED`: 支払い完了
- `PENDING` → `CANCELLED`: ユーザーキャンセル
- `CONFIRMED` → `PREPARING`: 店舗が準備開始
- `PREPARING` → `SHIPPED`: 配送開始
- `SHIPPED` → `DELIVERED`: 配達完了
- `PENDING`のみキャンセル可能

### 3.2 実装詳細

[`OrderServiceImpl.createOrder()`](file:///home/manglai/Projects/food-del-server-java/src/main/java/com/fooddel/service/impl/OrderServiceImpl.java#L47-L105)

```java
@Transactional
public Order createOrder(Integer userId, OrderRequest orderRequest) {
    // 1. ユーザーとカートを取得
    User user = userRepository.findById(userId)
        .orElseThrow(() -> new BusinessException("ユーザーが見つかりません"));
    Cart cart = cartService.getCartByUserId(userId);
    
    if (cart.getCartItems().isEmpty()) {
        throw new BusinessException("カートが空です");
    }
    
    // 2. 注文アイテムと合計金額を計算
    List<OrderItem> orderItems = new ArrayList<>();
    BigDecimal totalAmount = BigDecimal.ZERO;
    
    for (CartItem cartItem : cart.getCartItems()) {
        // 悲観的ロックで商品を取得
        Food food = foodRepository.findByIdWithLock(cartItem.getFood().getId())
            .orElseThrow(() -> new BusinessException("商品が見つかりません"));
        
        // 在庫チェック
        if (food.getStock() < cartItem.getQuantity()) {
            throw new BusinessException("在庫不足です: " + food.getName());
        }
        
        // 注文アイテムを作成
        OrderItem orderItem = new OrderItem();
        orderItem.setFood(food);
        orderItem.setQuantity(cartItem.getQuantity());
        orderItem.setPrice(food.getPrice());  // 注文時の価格を記録
        orderItems.add(orderItem);
        
        // 合計金額を計算
        totalAmount = totalAmount.add(
            food.getPrice().multiply(BigDecimal.valueOf(cartItem.getQuantity()))
        );
        
        // 在庫を更新
        food.setStock(food.getStock() - cartItem.getQuantity());
        food.setReserved(food.getReserved() - cartItem.getQuantity());
        foodRepository.save(food);
    }
    
    // 3. 注文エンティティを作成
    Order order = new Order();
    order.setUser(user);
    order.setOrderDate(LocalDateTime.now());
    order.setTotalAmount(totalAmount);
    order.setStatus(OrderStatus.PENDING);
    order.setDeliveryAddress(orderRequest.getDeliveryAddress());
    order.setOrderItems(orderItems);
    
    // 注文アイテムに注文をセット（双方向関連）
    orderItems.forEach(item -> item.setOrder(order));
    
    // 4. 注文を保存
    Order savedOrder = orderRepository.save(order);
    
    // 5. カートを空にする
    cartService.clearCart(userId);
    
    return savedOrder;
}
```

**重要ポイント**:

1. **悲観的ロック**: 並行注文を防ぐ
2. **価格記録**: 注文時の価格を保存（後で価格変更されても影響なし）
3. **在庫減算**: `stock`と`reserved`の両方を更新
4. **トランザクション**: 全てが成功するか、全て失敗する

## 4. 注文キャンセル

### 4.1 キャンセルフロー

```java
@Transactional
public Order cancelOrder(Integer userId, Integer orderId) {
    // 1. 注文を取得
    Order order = findOrderById(orderId)
        .orElseThrow(() -> new BusinessException("注文が見つかりません"));
    
    // 2. 権限チェック
    if (!order.getUser().getId().equals(userId)) {
        throw new BusinessException("この注文をキャンセルする権限がありません");
    }
    
    // 3. ステータスチェック
    if (order.getStatus() != OrderStatus.PENDING) {
        throw new BusinessException("この注文はキャンセルできません");
    }
    
    // 4. 在庫を返却
    for (OrderItem item : order.getOrderItems()) {
        Food food = item.getFood();
        food.setStock(food.getStock() + item.getQuantity());
        foodRepository.save(food);
    }
    
    // 5. 注文ステータスを更新
    order.setStatus(OrderStatus.CANCELLED);
    return orderRepository.save(order);
}
```

**キャンセル条件**:

- ✅ 自分の注文のみ
- ✅ `PENDING`ステータスのみ
- ✅ 在庫を返却

## 6. エンティティ設計

### 6.1 Order エンティティ

```java
@Entity
@Table(name = "orders")
public class Order {
    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Integer id;
    
    @ManyToOne
    @JoinColumn(name = "user_id")
    private User user;
    
    private LocalDateTime orderDate;
    private BigDecimal totalAmount;
    
    @Enumerated(EnumType.STRING)
    private OrderStatus status;
    
    private String deliveryAddress;
    
    @OneToMany(mappedBy = "order", cascade = CascadeType.ALL)
    private List<OrderItem> orderItems;
    
    @CreatedDate
    private LocalDateTime createdAt;
    
    @LastModifiedDate
    private LocalDateTime updatedAt;
}
```

### 6.2 OrderItem エンティティ

```java
@Entity
public class OrderItem {
    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Integer id;
    
    @ManyToOne
    @JoinColumn(name = "order_id")
    private Order order;
    
    @ManyToOne
    @JoinColumn(name = "food_id")
    private Food food;
    
    private Integer quantity;
    private BigDecimal price;  // 注文時の価格
    
    @CreatedDate
    private LocalDateTime createdAt;
    
    @LastModifiedDate
    private LocalDateTime updatedAt;
}
```
