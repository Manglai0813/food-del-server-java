## 1. 概要

カートシステムは、ユーザーが購入したい商品を一時的に保管する機能です。

**主な機能**:

- ✅ 商品の追加
- ✅ 数量の更新
- ✅ 商品の削除
- ✅ カートのクリア
- ✅ 在庫予約の管理

## 2. カート操作

### 2.1 カート取得

```java
@Transactional(readOnly = true)
public Cart getCartByUserId(Integer userId) {
    return cartRepository.findByUserId(userId)
        .orElseGet(() -> createNewCart(userId));
}
```

**ポイント**: カートが存在しない場合は自動作成

### 2.2 商品追加

```java
@Transactional
public Cart addItemToCart(Integer userId, CartItemRequest request) {
    Cart cart = getCartByUserId(userId);
    Food food = foodRepository.findById(request.getFoodId())
        .orElseThrow(() -> new BusinessException("商品が見つかりません"));
    
    // 在庫チェック
    if ((food.getStock() - food.getReserved()) < request.getQuantity()) {
        throw new BusinessException("在庫が不足しています");
    }
    
    // 既存アイテムチェック
    Optional<CartItem> existingItem = cart.getCartItems().stream()
        .filter(item -> item.getFood().getId().equals(request.getFoodId()))
        .findFirst();
    
    existingItem.ifPresentOrElse(
        item -> {
            item.setQuantity(item.getQuantity() + request.getQuantity());
            food.setReserved(food.getReserved() + request.getQuantity());
        },
        () -> {
            CartItem newItem = new CartItem();
            newItem.setCart(cart);
            newItem.setFood(food);
            newItem.setQuantity(request.getQuantity());
            cart.getCartItems().add(newItem);
            food.setReserved(food.getReserved() + request.getQuantity());
        }
    );
    
    foodRepository.save(food);
    return cartRepository.save(cart);
}
```

### 2.3 数量更新

```java
@Transactional
public Cart updateItemInCart(Integer userId, Integer cartItemId, 
                             CartItemRequest request) {
    Cart cart = getCartByUserId(userId);
    CartItem cartItem = findCartItemInCart(cart, cartItemId);
    
    int oldQuantity = cartItem.getQuantity();
    int newQuantity = request.getQuantity();
    int diff = newQuantity - oldQuantity;
    
    Food food = cartItem.getFood();
    
    if (diff > 0) {
        if ((food.getStock() - food.getReserved()) < diff) {
            throw new BusinessException("在庫が不足しています");
        }
    }
    
    food.setReserved(food.getReserved() + diff);
    foodRepository.save(food);
    
    cartItem.setQuantity(newQuantity);
    return cartRepository.save(cart);
}
```

### 2.4 商品削除

```java
@Transactional
public Cart removeItemFromCart(Integer userId, Integer cartItemId) {
    Cart cart = getCartByUserId(userId);
    CartItem cartItem = findCartItemInCart(cart, cartItemId);
    
    Food food = cartItem.getFood();
    food.setReserved(food.getReserved() - cartItem.getQuantity());
    foodRepository.save(food);
    
    cart.getCartItems().remove(cartItem);
    cartItemRepository.delete(cartItem);
    
    return cartRepository.save(cart);
}
```

### 2.5 カートクリア

```java
@Transactional
public void clearCart(Integer userId) {
    Cart cart = getCartByUserId(userId);
    cart.getCartItems().clear();
    cartRepository.save(cart);
}
```

**注意**: 予約解除は注文作成時に行われるため、ここでは不要

## 3. 在庫予約との連携

### 3.1 予約のライフサイクル

```
カート追加 → reserved += quantity
    ↓
数量更新 → reserved += diff
    ↓
商品削除 → reserved -= quantity
    ↓
注文作成 → reserved -= quantity (stock -= quantity)
```

### 3.2 エンティティ設計

```java
@Entity
public class Cart {
    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Integer id;
    
    @OneToOne
    @JoinColumn(name = "user_id")
    private User user;
    
    @OneToMany(mappedBy = "cart", cascade = CascadeType.ALL, orphanRemoval = true)
    private List<CartItem> cartItems = new ArrayList<>();
}

@Entity
public class CartItem {
    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Integer id;
    
    @ManyToOne
    @JoinColumn(name = "cart_id")
    private Cart cart;
    
    @ManyToOne
    @JoinColumn(name = "food_id")
    private Food food;
    
    private Integer quantity;
    
    @CreatedDate
    private LocalDateTime createdAt;
    
    @LastModifiedDate
    private LocalDateTime updatedAt;
}
```
