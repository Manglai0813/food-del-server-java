## 2. テーブル設計

### 2.1 users テーブル

```sql
CREATE TABLE users (
    id SERIAL PRIMARY KEY,
    name VARCHAR(100) NOT NULL,
    email VARCHAR(255) UNIQUE NOT NULL,
    password VARCHAR(255) NOT NULL,
    role VARCHAR(20) NOT NULL DEFAULT 'USER',
    refresh_token TEXT,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

**フィールド説明**:

- `id`: 主キー
- `email`: ログインID（ユニーク制約）
- `password`: BCrypt暗号化済みパスワード
- `role`: `USER` または `ADMIN`
- `refresh_token`: リフレッシュトークン

### 2.2 food テーブル

```sql
CREATE TABLE food (
    id SERIAL PRIMARY KEY,
    name VARCHAR(200) NOT NULL,
    description TEXT,
    price DECIMAL(10, 2) NOT NULL,
    image_path VARCHAR(500),
    status BOOLEAN DEFAULT TRUE,
    stock INTEGER NOT NULL DEFAULT 0,
    reserved INTEGER NOT NULL DEFAULT 0,
    min_stock INTEGER DEFAULT 10,
    category_id INTEGER REFERENCES category(id),
    version BIGINT DEFAULT 0,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    CONSTRAINT chk_stock CHECK (stock >= 0),
    CONSTRAINT chk_reserved CHECK (reserved >= 0),
    CONSTRAINT chk_reserved_stock CHECK (reserved <= stock)
);
```

**フィールド説明**:

- `stock`: 実在庫数
- `reserved`: 予約済み数
- `version`: 楽観的ロック用
- `status`: ソフトデリートフラグ

### 2.3 cart テーブル

```sql
CREATE TABLE cart (
    id SERIAL PRIMARY KEY,
    user_id INTEGER UNIQUE REFERENCES users(id),
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

### 2.4 cart_item テーブル

```sql
CREATE TABLE cart_item (
    id SERIAL PRIMARY KEY,
    cart_id INTEGER REFERENCES cart(id) ON DELETE CASCADE,
    food_id INTEGER REFERENCES food(id),
    quantity INTEGER NOT NULL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    UNIQUE(cart_id, food_id)
);
```

### 2.5 orders テーブル

```sql
CREATE TABLE orders (
    id SERIAL PRIMARY KEY,
    user_id INTEGER REFERENCES users(id),
    order_date TIMESTAMP NOT NULL,
    total_amount DECIMAL(10, 2) NOT NULL,
    status VARCHAR(20) NOT NULL,
    delivery_address TEXT NOT NULL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

### 2.6 order_item テーブル

```sql
CREATE TABLE order_item (
    id SERIAL PRIMARY KEY,
    order_id INTEGER REFERENCES orders(id),
    food_id INTEGER REFERENCES food(id),
    quantity INTEGER NOT NULL,
    price DECIMAL(10, 2) NOT NULL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

### 2.7 category テーブル

```sql
CREATE TABLE category (
    id SERIAL PRIMARY KEY,
    name VARCHAR(100) NOT NULL,
    description TEXT,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

## 3. インデックス設計

### 3.1 パフォーマンス向上のためのインデックス

```sql
-- ユーザー検索
CREATE INDEX idx_users_email ON users(email);

-- 商品検索
CREATE INDEX idx_food_category_id ON food(category_id);
CREATE INDEX idx_food_status ON food(status);
CREATE INDEX idx_food_stock ON food(stock);

-- カート検索
CREATE INDEX idx_cart_user_id ON cart(user_id);
CREATE INDEX idx_cart_item_cart_id ON cart_item(cart_id);
CREATE INDEX idx_cart_item_food_id ON cart_item(food_id);

-- 注文検索
CREATE INDEX idx_orders_user_id ON orders(user_id);
CREATE INDEX idx_orders_status ON orders(status);
CREATE INDEX idx_orders_order_date ON orders(order_date);
CREATE INDEX idx_order_item_order_id ON order_item(order_id);
```

## 4. リレーションシップ

### 4.1 一対一 (1:1)

- `User` ↔ `Cart`: 1ユーザーに1カート

### 4.2 一対多 (1:N)

- `User` → `Order`: 1ユーザーが複数注文
- `Category` → `Food`: 1カテゴリに複数商品
- `Cart` → `CartItem`: 1カートに複数アイテム
- `Order` → `OrderItem`: 1注文に複数アイテム

### 4.3 多対多 (M:N)

- `Cart` ↔ `Food`: CartItemを介して
- `Order` ↔ `Food`: OrderItemを介して

## 5. データ整合性

### 5.1 外部キー制約

- すべてのリレーションシップに外部キー設定
- 参照整合性の保証

### 5.2 CHECK制約

- `stock >= 0`: 在庫は0以上
- `reserved >= 0`: 予約は0以上
- `reserved <= stock`: 予約は在庫以下

### 5.3 UNIQUE制約

- `users.email`: メールアドレスの重複防止
- `cart_item(cart_id, food_id)`: カート内の商品重複防止
