## 1. 開発環境セットアップ

### 1.1 必要なソフトウェア

| ソフトウェア | バージョン | 用途 |
|------------|----------|------|
| Java | 21+ | アプリケーション実行 |
| PostgreSQL | 15+ | データベース |
| Redis | 7+ | キャッシュ・トークン管理 |
| Gradle | 8+ | ビルドツール |

### 1.2 Java 21 インストール

#### SDKMANを使用（推奨）

```bash
# SDKMANインストール
curl -s "https://get.sdkman.io" | bash
source "$HOME/.sdkman/bin/sdkman-init.sh"

# Java 21インストール
sdk install java 21-open
sdk use java 21-open

# 確認
java -version
```

#### 手動インストール

- [OpenJDK 21](https://jdk.java.net/21/)をダウンロード
- 環境変数`JAVA_HOME`を設定

### 1.3 PostgreSQLセットアップ

#### インストール

```bash
# Ubuntu/Debian
sudo apt update
sudo apt install postgresql postgresql-contrib

# macOS
brew install postgresql@15

# Fedora
sudo dnf install postgresql-server postgresql-contrib
```

#### データベース作成

```bash
# PostgreSQLに接続
sudo -u postgres psql

# データベース作成
CREATE DATABASE fooddb;

# ユーザー作成（オプション）
CREATE USER fooduser WITH PASSWORD 'your_password';
GRANT ALL PRIVILEGES ON DATABASE fooddb TO fooduser;

# 終了
\q
```

### 1.4 Redisセットアップ

```bash
# Ubuntu/Debian
sudo apt install redis-server

# macOS
brew install redis

# Fedora
sudo dnf install redis

# 起動
redis-server

# 確認
redis-cli ping
# 応答: PONG
```

## 2. ローカル実行

### 2.1 プロジェクトクローン

```bash
git clone https://github.com/your-repo/food-del-server-java.git
cd food-del-server-java
```

### 2.2 設定ファイル編集

`src/main/resources/application.yml`を編集：

```yaml
spring:
  datasource:
    url: jdbc:postgresql://localhost:5432/fooddb
    username: postgres
    password: your_password
  
  data:
    redis:
      host: localhost
      port: 6379

app:
  jwt:
    secret: your-256-bit-secret-key-here
    refresh-secret: your-refresh-secret-key-here
```

### 2.3 ビルドと実行

```bash
# ビルド
./gradlew clean build

# 実行
./gradlew bootRun

# または
java -jar build/libs/food-del-server-0.0.1-SNAPSHOT.jar
```

### 2.4 動作確認

```bash
# ヘルスチェック
curl http://localhost:5000/actuator/health

# Swagger UI
open http://localhost:5000/swagger-ui.html
```

## 3. Docker デプロイ

### 3.1 Dockerfileを作成

`Dockerfile`:

```dockerfile
FROM eclipse-temurin:21-jre-alpine

WORKDIR /app

COPY build/libs/*.jar app.jar

EXPOSE 5000

ENTRYPOINT ["java", "-jar", "app.jar"]
```

### 3.2 docker-compose.ymlを作成

`docker-compose.yml`:

```yaml
version: '3.8'

services:
  app:
    build: .
    ports:
      - "5000:5000"
    environment:
      - SPRING_DATASOURCE_URL=jdbc:postgresql://db:5432/fooddb
      - SPRING_DATASOURCE_USERNAME=postgres
      - SPRING_DATASOURCE_PASSWORD=postgres
      - SPRING_DATA_REDIS_HOST=redis
      - JWT_SECRET=${JWT_SECRET}
      - JWT_REFRESH_SECRET=${JWT_REFRESH_SECRET}
    depends_on:
      - db
      - redis
    networks:
      - fooddel-network

  db:
    image: postgres:15-alpine
    environment:
      - POSTGRES_DB=fooddb
      - POSTGRES_USER=postgres
      - POSTGRES_PASSWORD=postgres
    volumes:
      - postgres-data:/var/lib/postgresql/data
    ports:
      - "5432:5432"
    networks:
      - fooddel-network

  redis:
    image: redis:7-alpine
    ports:
      - "6379:6379"
    networks:
      - fooddel-network

volumes:
  postgres-data:

networks:
  fooddel-network:
    driver: bridge
```

### 3.3 Docker実行

```bash
# ビルド
./gradlew clean build

# Docker起動
docker-compose up -d

# ログ確認
docker-compose logs -f app

# 停止
docker-compose down

# データも削除
docker-compose down -v
```

## 4. 本番環境デプロイ

### 4.1 本番用設定

`src/main/resources/application-prod.yml`:

```yaml
spring:
  datasource:
    url: ${DATABASE_URL}
    username: ${DATABASE_USERNAME}
    password: ${DATABASE_PASSWORD}
    hikari:
      maximum-pool-size: 20
      minimum-idle: 5
  
  jpa:
    show-sql: false
    hibernate:
      ddl-auto: validate

logging:
  level:
    com.fooddel: INFO
    root: WARN

server:
  port: ${PORT:5000}
```

### 4.2 環境変数設定

```bash
# 必須環境変数
export SPRING_PROFILES_ACTIVE=prod
export DATABASE_URL=jdbc:postgresql://your-db-host:5432/fooddb
export DATABASE_USERNAME=your_username
export DATABASE_PASSWORD=your_password
export JWT_SECRET=your-production-secret-key
export JWT_REFRESH_SECRET=your-production-refresh-secret-key
export REDIS_HOST=your-redis-host
export REDIS_PORT=6379
```

### 4.3 ビルドと起動

```bash
# ビルド（テストスキップ）
./gradlew clean build -x test

# 実行
java -jar \
  -Dspring.profiles.active=prod \
  -Xms512m \
  -Xmx1024m \
  build/libs/food-del-server-0.0.1-SNAPSHOT.jar
```

### 4.4 systemdサービス化（Linux）

`/etc/systemd/system/fooddel.service`:

```ini
[Unit]
Description=Food Delivery Platform
After=network.target

[Service]
Type=simple
User=fooddel
WorkingDirectory=/opt/fooddel
ExecStart=/usr/bin/java -jar \
  -Dspring.profiles.active=prod \
  -Xms512m -Xmx1024m \
  /opt/fooddel/food-del-server.jar
Restart=on-failure
RestartSec=10

[Install]
WantedBy=multi-user.target
```

```bash
# サービス有効化
sudo systemctl enable fooddel
sudo systemctl start fooddel

# ステータス確認
sudo systemctl status fooddel

# ログ確認
sudo journalctl -u fooddel -f
```

## 5. 環境変数設定

### 5.1 必須環境変数

| 変数名 | 説明 | 例 |
|--------|------|-----|
| `SPRING_PROFILES_ACTIVE` | アクティブプロファイル | `prod` |
| `DATABASE_URL` | データベースURL | `jdbc:postgresql://...` |
| `DATABASE_USERNAME` | DBユーザー名 | `fooduser` |
| `DATABASE_PASSWORD` | DBパスワード | `***` |
| `JWT_SECRET` | JWTシークレット | 256ビット文字列 |
| `JWT_REFRESH_SECRET` | リフレッシュトークンシークレット | 256ビット文字列 |
| `REDIS_HOST` | Redisホスト | `localhost` |
| `REDIS_PORT` | Redisポート | `6379` |

### 5.2 オプション環境変数

| 変数名 | 説明 | デフォルト |
|--------|------|----------|
| `PORT` | サーバーポート | `5000` |
| `LOG_LEVEL` | ログレベル | `INFO` |
| `MAX_POOL_SIZE` | DB接続プール最大数 | `10` |

## 7. バックアップ

### 7.1 データベースバックアップ

```bash
# バックアップ
pg_dump -U postgres fooddb > backup_$(date +%Y%m%d).sql

# リストア
psql -U postgres fooddb < backup_20240101.sql
```

### 7.2 自動バックアップ（cron）

```bash
# crontab -e
0 2 * * * /usr/bin/pg_dump -U postgres fooddb > /backups/fooddb_$(date +\%Y\%m\%d).sql
```
